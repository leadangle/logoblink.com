These are the football logos of 2008! This includes all teams which are going to take part in the Euro 2008 football games. Congrats to the Spanish fans! For those of you who don’t follow sports or football (soccer if you want) in particular, Spain is the 2008 UEFA champion.

  1. Czech Republic ( too detailed, overcrowded )
  2. Portugal ( ball is missing )
  3. Switzerland ( the most designed one )
  4. Turkey ( too simple )
  5. Croatia ( it works )
  6. Austria ( American styled, too corporate )
  7. Germany ( build to last )
  8. Poland ( it works )
  9. France ( ball missing, unpractical gradients )
 10. Italy ( nice shirts design, bad logo )
 11. Netherlands ( ball missing, but practical and easy to recognize )
 12. Romania ( lack of creativity )
 13. Greece ( it works )
 14. Russia ( great elements, but it could be better )
 15. Spain ( arty-smarty )
 16. Sweden ( ball and elements too small )

**The football logos in numbers:**

**6 of 16 logos** do have circle shape (based on the ball shape);

**6 of 16 logos** do have  shield shape (based on the national emblem);

**3 of 16 logos** are monochrome;

**12 of 16** **logos** do have an obvious “football ball” reference.
